# Πίνακες Σύστασης Ιδιοκτησίας

Εργαλείο μηχανικού για τους πίνακες που παραδίδονται στη συμβολαιογράφο για σύσταση οριζόντιας/κάθετης ιδιοκτησίας: χιλιοστά, αναλογία γης, αποκλειστικές χρήσεις (κήποι, πισίνες, θέσεις στάθμευσης), κοινόχρηστα και κατανομή δαπανών, έλεγχοι και εξαγωγή σε PDF / Excel.

## Πολλά κτίρια σε ένα οικόπεδο
- **Οριζόντια ιδιοκτησία** με κτίρια: κάθε ιδιοκτησία παίρνει ‰ απευθείας επί του οικοπέδου· τα κτίρια ομαδοποιούν τις γραμμές.
- **Κάθετη και οριζόντια ιδιοκτησία** (δύο επίπεδα): κάθε κτίριο είναι κάθετη ιδιοκτησία με ‰ επί του οικοπέδου (αυτόματα από τα εμβαδά, κατά την αποκλειστική χρήση γης του, ή χειροκίνητα). Κάθε οριζόντια ιδιοκτησία παίρνει ‰ επί του κτιρίου της (1000‰ ανά κτίριο) και ‰ επί του οικοπέδου = ‰ κτιρίου × ‰ επί κτιρίου / 1000, στρογγυλεμένα ώστε να κλείνουν ακριβώς σε κάθε επίπεδο.
- Αποκλειστικές χρήσεις μπορούν να δοθούν σε κτίριο (τμήμα γηπέδου της κάθετης ιδιοκτησίας) ή σε ιδιοκτησία. Κοινόχρηστα «ανά κτίριο» ακολουθούν αυτόματα τις ιδιοκτησίες του.

## Μέθοδος χιλιοστών και κατανομές δαπανών
- **Βάση:** εμβαδόν ή όγκος (εμβαδόν × ύψος ιδιοκτησίας, με προεπιλεγμένο ύψος).
- **Συντελεστής αξίας ανά στάθμη** (προαιρετικά): υπόγειο 0,50 · ισόγειο 1,00 · +5% ανά όροφο, με αλλαγή ανά στάθμη.
- **Κλείδωμα ‰:** όποια ιδιοκτησία έχει τιμή την κρατά· οι υπόλοιπες μοιράζονται αναλογικά το υπόλοιπο ως τα 1000‰ (και μέσα σε κτίριο, και σε κάθε κατανομή δαπανών).
- **Κατανομές δαπανών:** ισόποσα, κατά τα χιλιοστά, κατά τον όγκο, ανελκυστήρας (όγκος × συντελεστής ορόφου: υπόγειο 0,50 · ισόγειο 0 · α΄ 1,00 · +10%), θέρμανση (όγκος × συντελεστής από μελέτη μηχανολόγου), χειροκίνητα.
- **Ψήφοι:** ακέραια ‰ από τα χιλιοστά οικοπέδου, που κλείνουν ακριβώς στα 1000.
- **Υπόμνημα** κάτω από τον πίνακα, με έτοιμες τυπικές σημειώσεις.

Η μέθοδος ακολουθεί την πρακτική του «Πίνακα αναλογισμού – κατανομής χιλιοστών» (Ν. Μαυρογένης)· η στρογγυλοποίηση εδώ γίνεται με τη μέθοδο του μεγαλύτερου υπολοίπου, ώστε κάθε σύνολο να κλείνει ακριβώς.

## Τεχνολογία
- **Vite** (vanilla JS), χωρίς framework
- **Supabase**: login (email/κωδικός), Postgres με RLS — κάθε χρήστης βλέπει μόνο τα δικά του έργα
- Κάθε έργο είναι ένα έγγραφο `jsonb` (`projects.data`), ώστε νέα πεδία να μη χρειάζονται migration
- Αυτόματο ιστορικό εκδόσεων (`project_versions`) και «κάδος» για διαγραμμένα έργα
- Τοπικό αντίγραφο σε κάθε συσκευή: αν πέσει το internet, οι αλλαγές φυλάσσονται και στέλνονται μόλις επανέλθει

## Δομή
| Αρχείο | Τι κάνει |
|---|---|
| `src/core.js` | Όλοι οι υπολογισμοί (χιλιοστά, αναλογίες, ισοζύγιο, έλεγχοι). Χωρίς DOM. |
| `src/main.js` | Διεπαφή, συγχρονισμός, εξαγωγές PDF/Excel |
| `src/store.js` | Κλήσεις στο Supabase |
| `supabase/migrations/` | Σχήμα βάσης (εφαρμοσμένο στο project `systasi`) |
| `tests/` | Τεστ υπολογισμών, σχήματος/RLS (PGlite) και διεπαφής (Playwright, προσομοίωση Supabase) |

## Τοπικά
```bash
npm install
cp .env.example .env   # URL και publishable key του Supabase project
npm run dev            # http://localhost:5173
npm test               # τεστ υπολογισμών και βάσης
```

## Δημοσίευση (Vercel)
1. Vercel → Add New → Project → Import αυτό το repo (Framework: Vite, χωρίς άλλες ρυθμίσεις).
2. Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` (τιμές στο `.env.example`).
3. Supabase → Authentication → URL Configuration: **Site URL** = η διεύθυνση του Vercel, και στα **Redirect URLs** η ίδια διεύθυνση και `http://localhost:5173`.

Κάθε `git push` στο `main` δημοσιεύεται αυτόματα.
